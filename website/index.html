04 / Privacy you can explain

Less to link.
More you can verify.

Your route

The relay is designed to hide the agent’s source IP from destinations. It still sees the agent IP and destination host.

Your payment

Blind signatures separate token issuance from redemption. Merchants receive valid tokens, not your top-up wallet.

Your verification

The SDK checks the issuer’s attested code and keys on Google Confidential Space. Attestation verifies the workload, not what an operator may log outside it.

The honest boundary

Websites can log requests. Logins, API keys and timing can identify an agent. Wraps does not promise total anonymity.

Where the prototype is today

Blind-token payments and issuer attestation are implemented. The metered relay exists; end-to-end VPN integration is still in progress.
