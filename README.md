# Incognito mode for agents 

XRPL AI & Fintech Hackathon (NYC, Oct 24 to 25, 2026).

Agents refill their budget through Mastercard AP4M, then pay merchants with blind tokens (RFC 9578) through an attested relay. The issuer and relay run in AWS Nitro Enclaves.

The full design is in [docs/SPEC.md](docs/SPEC.md).
