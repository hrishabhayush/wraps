How Wraps works.

Three parts, each checkable. No party sees both who you are and what you do.

Verified

Proven no-log servers

Nodes and the token issuer run open code in confidential VMs, hardware-attested by AMD SEV, verified by Google. Before you connect or pay, the app checks the attestation names the exact code. A modified or debug build is refused.

IMAGE_MISMATCH → refused

Private

Payments that can't be linked

Top up once with RLUSD from your own wallet on the XRPL EVM sidechain. The issuer signs blind tokens (Privacy Pass, RFC 9578): it can tell a token is valid and unspent, but not which payment it came from.

Metered

Pay only while connected

Tokens are spent per chunk of traffic while you're connected. No subscription.

Incognito mode for your agents.

Your agent's tool calls, browsing and payments go through the same attested no-log VPN, paid per use with blind tokens. Sites, merchants and the public chain can't build a record of it.

agent.tsIllustrative
// Check the attestation, then pay per call with blind tokens.
const wraps = new PrivatePayClient({
  issuerUrl: 'https://issuer.example',
  verifier,                // refuses debug or modified builds
  wallet,                  // your RLUSD top-up wallet
  caps: { perCallTokens: 5, dailyTokens: 24, maxTopUpTokens: 20 },
});

await wraps.connect();   // attestation checked before any payment
const res = await wraps.fetch('https://api.example.com/prices');
// 402 → pays in tokens, under the caps. Above the cap: refused.
