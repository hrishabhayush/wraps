# Incognito mode for agents 


## Download (macOS, Apple Silicon)

**[Wraps v0.1.0 for Mac](https://github.com/hrishabhayush/wraps/releases/tag/v0.1.0)**: download the `.dmg`, drag Wraps to Applications, then right-click Wraps → Open the first time (the app isn't notarized yet). Wraps lives in the menu bar; press Option-Command-W if the notch hides it.

XRPL AI & Fintech Hackathon (NYC, Oct 24 to 25, 2026).

Agents refill their budget through Mastercard AP4M, then pay merchants with blind tokens (RFC 9578) through an attested relay. The issuer and relay run in AWS Nitro Enclaves.

The full design is in [docs/SPEC.md](docs/SPEC.md).
